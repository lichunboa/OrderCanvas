# Contributing to OrderCanvas open-source components

[中文说明](docs/OPEN_SOURCE.zh-CN.md) · [Scope and licenses](docs/OPEN_SOURCE.md)

Thanks for helping the MetaTrader 5 developer community!

We welcome pull requests for **`OpenUtilities/` (MIT)** and **`TVStudySuite/` (MPL-2.0)**: focused fixes, small tests, reproducible symbol/broker edge cases, source attribution corrections and docs.

The commercial OrderCanvas trade panel, UI engine, account licensing, build secrets and private service code are not part of the open-source contribution scope. A public issue does not authorize sharing proprietary source.

Before opening a PR:
1. Confirm your change is permitted by the target directory's license and that you own or may contribute the code. Preserve original authors' notices.
2. Explain what changed, why, how to reproduce it, and what tests ran. For `OpenUtilities`, see its README for C++ host-test commands.
3. Keep changes confined to open-source directories and their documentation. Do not bundle compiled commercial code.
4. Do not disclose MT5 account IDs, activation keys, private contact details, payment records, signing secrets or security vulnerabilities in public issues. Report sensitive issues privately through GitHub's security reporting facility if enabled, or use the official support route from the README.

Opening a PR does not change the license of any separate commercial component.
