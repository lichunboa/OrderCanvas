# Security policy

[Licensing & scope](docs/OPEN_SOURCE.md)

We welcome responsible reports about OrderCanvas's open-source utilities, TVStudySuite, installers and commercial product.

**Do not disclose a suspected vulnerability, an activation/signing secret, customer information or account/order data in a public issue or pull request.** If GitHub private vulnerability reporting is enabled for this repository, use the private **Report a vulnerability** option in its Security tab. If that option is unavailable, first request a secure contact channel using the official support route described in the main README; **do not include exploit details in that initial request**.

## What helps investigation

- An affected version or commit, platform and MT5 build;
- Steps to reproduce, with sanitized test inputs;
- Observed behavior versus expected behavior and likely impact;
- Whether this concerns the commercial EX5, an installer, the open workbench or a utility.

Never attach real account IDs, passwords, activation keys, signing secrets, payment information or broker transaction logs containing private details. Use demo or fabricated identifiers.

Security triage and remediation timing are assessed individually; this policy does not promise a fixed SLA or a public bounty.
