# OrderCanvas Community & Support

[中文](COMMUNITY.zh-CN.md) · [Developer guide](DEVELOPERS.md) · [Commercial installation](INSTALL.md)

OrderCanvas serves both traders and MQL5 developers. Choose the correct channel so account-specific support and public open-source issues do not get mixed.

| Need | Where to go | What belongs there |
|---|---|---|
| Official product overview and separately licensed download | [getordercanvas.com](https://getordercanvas.com/oc/shop?lang=en) | Official buyer site; Market orders remain on MQL5 |
| Install, trial, purchase, activation and account-specific support | [OrderCanvas Telegram bot](https://t.me/OrderCanvasbot) | Buyer questions, obtaining assistance and authorized support routes |
| Bug in OpenUtilities or TVStudySuite | [GitHub Issues](https://github.com/lichunboa/OrderCanvas/issues/new/choose) | Redacted reproduction, expected vs observed result, test case, MT5 build |
| Open-source change or technical fix | [GitHub Pull Requests](https://github.com/lichunboa/OrderCanvas/pulls) | MIT/MPL-2.0 source updates and docs, with provenance and tests |
| Security or privacy vulnerability | [Private reporting directions](../SECURITY.md) | Sensitive reports must *not* go into public Issues |
| Product changes and version notes | [Releases](https://github.com/lichunboa/OrderCanvas/releases) | Published downloads and changelogs |

**Community entry:** the Telegram bot is the stable public starting point. The user discussion group was configured and tested with the bot on 2026-10-15; choose **Join the community** inside the bot to obtain the currently valid invite URL. Do not publish private operations-group URLs or stale invitation tokens. Marketplace purchases and activations stay on the [official MQL5 Market listing](https://www.mql5.com/en/market/product/201771).

Community participation should be voluntary and moderated, not promotional spam. Maintainers disclose commercial affiliation, avoid invented testimonials or profit claims, and respect each platform's posting rules.

For all public posts, never share MT5 account numbers, order IDs, license keys, login credentials, payment details, screenshots containing personal information or private logs. Use demo data and redact sensitive identifiers.

Open-source contributors should also read [CONTRIBUTING.md](../CONTRIBUTING.md) and the [code of conduct](../CODE_OF_CONDUCT.md).
