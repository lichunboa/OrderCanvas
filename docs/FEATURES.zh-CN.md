# OrderCanvas 产品功能清单（1.9）

[English](FEATURES.md) · **中文**

OrderCanvas 是 MetaTrader 5 的图表交易面板（EA，“工具”类）：把现代交易平台式的下单、订单线、持仓管理和交易分析搬到 MT5 图表上。纯 MQL5，不用 DLL、不联网，Windows 和 macOS 都可用。

## 1.9 新增与改进一览

| 方向 | 内容 |
|---|---|
| 订单线 | 拖动止盈 / 止损 / 挂单线**松开即生效**（可改为先确认）；点击线上盈亏，编辑框出现在**这条线旁边**；把「半」拖出来做**分批止盈 / 分批止损**（标签显示比例和到价盈亏，副图同步显示）；副图上订单线**简化显示**，鼠标移上去展开 |
| 自动保护 | 追踪止损可选 **ATR / 摆动高低点 / 固定 R**，可开仓即追踪；新增**到 xR 自动部分平仓**；三个开关直接放进下单面板并写出规则 |
| 指标与模板 | 6 种模板预设（价格行为、纯净K线、趋势均线、布林+RSI、MACD、成交量）；指标改为 **TradingView 风格**并统一 2px（MACD 信号线 + 四色柱），价格行为 EMA 保持细虚线；K 线下面默认不显示成交量 |
| 多图工作区 | 副图只显示品种和周期按钮，可单独换品种；副图上**浅色带标出主图正在看的区间**；「还原单图」「放回 MT5 窗口」；订单面板放在指标下面的独立窗格 |
| 界面 | 暖色浅色主题、开关状态更明显、按功能设计的图标、点差偏大**变红提醒**；设置页难理解的项有 **ⓘ 说明**（悬停看计算逻辑） |
| 稳定性与性能 | 订单面板重绘开销从每帧约 7ms 降到约 0.3ms；修复小仓位加密货币按金额设置止盈止损时显示 0 tick、下单按钮变灰；矮窗口拖线不生效等问题 |
| 版本号 | 与 MQL5 市场一致的两段式版本号（1.9、1.10…） |

## 1. 下单面板（票据）

| 功能 | 说明 |
|---|---|
| 订单类型 | 市价、限价、止损、停损限价；挂单有效期 GTC / 当日 / 指定时间（带日历） |
| 数量的 5 种算法 | 手数、保证金金额、余额 %、风险金额、风险 %（按止损距离反算手数）；右侧显示等价值 |
| 止盈止损 | 各自开关；默认按**盈亏金额**（账户货币），也可用 tick、价格、% 价格、点、余额 %；右侧显示对应 tick；实时盈亏比，可**锁定比例**（改一个，另一个自动跟随） |
| 错误提示 | 无效的输入框上方直接写原因（方向、最小距离、最小手数所需金额），图上「!」悬停同样显示 |
| 颜色与线一致 | 止盈标题和金额为绿色、止损为琥珀色，与图上的止盈止损线一致；买入蓝、卖出红 |
| 自动保护开关 | 止盈止损下面一行：保本 +1R · 追踪 ATR×2 · 分批 1R·50%（按你的设置显示），点击开关，「设置 ›」进入详细参数 |
| 一键交易 | 标题栏开关：开启后点卖出 / 买入报价直接市价成交，底部按钮变为本品种「一键平仓」 |
| 收起模式 | 只保留方向、类型、数量和提交；订单类型和数量方式为下拉选择 |
| 订单预设 | 保存类型、价格偏移、止盈止损、有效期，最多 5 组（标题栏网格图标） |
| 布局 | 浮动拖动或停靠；切换订单类型时**只向下伸展**，不会挤到工具栏；窗口太矮时内容区滚动 |
| 信息 | 交易额、刻度值、所需保证金（券商数据）；被拦截时下单按钮第二行写明原因 |

## 2. 图表订单线

| 功能 | 说明 |
|---|---|
| 下单前预览 | 选方向后先画出入场 / 止盈 / 止损草稿线（虚线），确认后才发送 |
| 拖动改价 | 拖动入场、止盈、止损线；**松开即改单**（和 TradingView 一样）。设置里可改为松开后在线上显示「放弃 / 确认」 |
| 拉出止盈止损 | 按住订单线上的 TP / SL 直接拖出来，不用先点 |
| 持仓线操作 | `[数量 | 盈亏 | 保 | 半 | 反 | ×]`：保本（可计入手续费 ×2、隔夜利息、额外偏移）、部分平仓、反手、平仓；默认在鼠标旁确认，设置里可免确认 |
| 分批止盈 / 止损 | 把「半」**拖出来**：拖向盈利方向 = 分批止盈，拖向亏损方向 = 分批止损；标签显示比例和到价盈亏（如 TP2 · 25% · +41.50 USD），按住拖动改价，点击在 25 / 33 / 50 / 67 / 75 / 100% 间切换比例，× 删除。每个持仓分批止盈、分批止损**各最多 3 个**；所有图表（含副图）同步显示，同一品种只由一个图表执行；EA 执行，重启后保留 |
| 线旁编辑框 | 点击持仓盈亏或挂单标签，编辑框出现在这条线旁边：止损、止盈、移至保本、数量（持仓：减少 = 部分平仓，增加 = 加仓；挂单：按原价重新挂出新数量）、分批价位；交易面板保持可用 |
| 价格框 | 订单线右端价格框：点击输入价格，按住拖动移动 |
| 副图简化显示 | 副图上的订单线只显示手数和盈亏，鼠标移到线附近展开完整操作；可在设置里关闭 |
| 价格轴标记 | 每条线在价格轴上有对应价格标签，同一笔订单的线之间有连接线 |

## 3. 自动保护与风险上限（默认关闭）

| 功能 | 说明 |
|---|---|
| R 的定义 | 开仓时止损到开仓价的距离，第一次看到带止损的持仓时记录，之后不变，终端重启后保留 |
| 自动保本 | 盈利达到 +xR（0.5–10R，可自定义）时，止损移到开仓价 + 勾选的成本；每个持仓一次 |
| 追踪止损 | 每根 K 线收盘计算一次，只收紧不放宽。方式：**ATR(14) × 倍数**、**最近 N 根K线低点 / 高点**（卖单加点差）、**固定倍数 × R**；可「开仓后立即追踪」或保本后开始 |
| 自动部分平仓 | 盈利达到 +xR 时平掉 y%（按当时持仓量，取整到手数步长），每个持仓一次 |
| 经济日历 | MT5 自带日历，TradingView 式显示：图表底部每个公布时间一个小圆标（橙色 = 高影响），**鼠标放上去**显示时间线和简报（实际 / 预期 / 前值），**点击**看详情和最近 6 次公布值；高影响数据前工具栏提醒（默认提前 15 分钟），公布后约 2 秒出现实际值并在工具栏显示 3 分钟（按 MetaQuotes 判断，利好本币绿、利空红），显示前值修正；可选「重要数据前后暂停新开仓」（默认关闭）；GitHub / 商店版的详情里还显示相关央行 / 统计局的**官方发布**标题（公开 RSS，需允许联网，市场版不含） |
| 点差上限 | 本品种点差超过上限时拦截新开仓（平仓、改单不受影响）；工具栏点差明显偏大时变红，点击直达设置 |
| 单笔风险上限 | 按止损计算本单亏损占净值 %，超过上限不发单 |
| 运行条件 | 需要 MT5 和这张图表保持打开（EA 执行，不是券商服务器上的单），只管理本面板魔术号 |
| 说明图标 | 设置页每个相关项旁有 ⓘ，悬停显示计算逻辑和例子 |

## 4. 快捷操作

| 功能 | 说明 |
|---|---|
| 快捷键 | 设置里直接输入单键或组合（B、Shift+S、Ctrl+Shift+X、F2）：市价买 / 卖、平仓、保本、部分平仓、收起 / 展开；冷却时间防重复 |
| 跟随鼠标 | Shift+B / Shift+S：订单跟着鼠标，点击下单（按位置自动判断限价或止损）；L / P：止损 / 止盈跟随鼠标（草稿或最新持仓 / 挂单），显示到该价位的盈亏；左键确定、右键或 Esc 取消 |
| 订单类型循环 | Shift+T 在勾选的类型间循环，也可直接切到限价 / 止损 / 市价 |
| 工具栏开关 | 快捷键默认关闭，工具栏一键开启，悬停查看全部键位 |

## 5. 工作区与图表

| 功能 | 说明 |
|---|---|
| 工具栏 | 设置、品种搜索、周期、模板、副图、订单面板、下单面板、快捷键、帮助；图标按功能设计，可只显示图标；开启的项有底色 |
| 模板预设 | 价格行为（官方工作台）、纯净K线、趋势均线 EMA 20/50/200、布林带 + RSI、MACD + EMA20、成交量 + EMA20；也可保存和管理自己的模板。预设只替换它自己加的指标，你加的保留 |
| TradingView 风格指标 | OC EMA、OC BB、OC RSI（70/50/30）、OC MACD（MACD 线、信号线、四色柱）、OC Volume（按K线涨跌着色 + 均量）、OC ATR，统一 2px，都可以照常编辑、删除 |
| 副图与多图布局 | 「副图」打开本品种任意周期的真正 MT5 图表，8 种布局（如左二右大）；副图只显示品种和周期按钮，可单独换品种；默认自动缩放，周期菜单里可切换自由纵轴、图表偏移、自动滚动、回到最新K线 |
| 主图区间标记 | 副图上用浅色带标出主图当前显示的时间段（副图整屏都在主图范围内时不显示） |
| 还原 | 「还原单图」关闭副图只留主图；「放回 MT5 窗口」保留副图，Alt+R 可平铺 |
| 订单面板 | 在指标下面的独立窗格：持仓 / 订单 / 历史 / 账户 / 分析；排序、合计、悬停高亮对应订单线、最大化、一键全部平仓 |
| 交易分析 | 策略报告式：关键指标、资金曲线与回撤、盈亏结构、胜负、分布、多空、按星期 / 持有时长 / 平仓小时，绩效 / 风险 / 品种表；每笔交易的实际风险（MAE） |
| 图表操作 | 滚轮缩放、拖动平移、纵轴自由缩放（双击纵轴回到自动）、新K线到来时从你停留的位置继续、K 线收盘倒计时 |
| 主题 | 浅色（暖色护眼）/ 深色 / 自动（跟随图表背景），副图跟随主图 |
| 点差 | 工具栏实时点差；明显高于本品种平常或超过上限时变红并提示 |
| 价格行为工作台 | 内置开源 **TVStudySuite**（MPL-2.0）：EMA、缺口、内包 / 外包、昨日高低点、K线计数、H1/H2/L1/L2 信号 |
| 新手引导 | 6 步可移动引导，每步一个小任务 |
| 品种搜索 | 按类别和交易所分组、自选、键盘选择 |

## 6. 安全、兼容与性能

| 功能 | 说明 |
|---|---|
| 账户类型 | 对冲、净额、交易所账户（净额部分平仓用反向成交） |
| 真实账户 | 首次使用弹出风险确认；可选「仅允许模拟账户」 |
| 魔术号隔离 | 只管理本面板魔术号的订单，其他订单只读显示 |
| 精确身份 | 每个修改 / 平仓都绑定订单号、账户、品种、魔术号，界面变化后的旧点击会被拒绝 |
| 以券商为准 | 每次交易后从终端的持仓和挂单重建图上订单线，不保存影子状态 |
| 兼容 | 不锁定图表上的其他指标；ATR 等可以自由编辑删除；与其他 EA 的订单互不干扰 |
| 性能 | Canvas 按脏区刷新；拖动每帧约 1.3ms；订单面板稳态重绘约 0.3ms |
| 平台 | Windows 与 macOS（Wine）都测试过，文字随屏幕 DPI 缩放；策略测试器可用（免授权） |
| 语言 | 中文 / English / 跟随终端 |
| 授权 | 授权码绑定 MT5 账户号，离线校验 |
