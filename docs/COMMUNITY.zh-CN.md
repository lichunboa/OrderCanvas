# OrderCanvas 社区与支持入口

[English](COMMUNITY.md) · [开发者指南](DEVELOPERS.zh-CN.md) · [产品安装指南](INSTALL.md)

OrderCanvas 同时面向交易用户和 MQL5 开发者。两类问题分别处理，避免把私密授权信息放进公开 GitHub。

| 你的需求 | 推荐渠道 | 适合的问题 |
|---|---|---|
| 正式官网与独立授权下载 | [getordercanvas.com](https://getordercanvas.com/oc/shop?lang=zh) | 官方买家站；MQL5 Market 订单仍在平台内办理 |
| 安装、购买、试用、授权、账号相关咨询 | [OrderCanvas Telegram Bot](https://t.me/OrderCanvasbot) | 买家咨询、联系支持渠道、账户相关售后 |
| 开源模块 Bug、兼容问题 | [GitHub Issues](https://github.com/lichunboa/OrderCanvas/issues/new/choose) | 脱敏复现步骤、测试输入、MT5 build、预期与实际 |
| 开源修复与代码贡献 | [GitHub Pull Requests](https://github.com/lichunboa/OrderCanvas/pulls) | MIT/MPL-2.0 代码、测试、文档和来源说明 |
| 安全漏洞、隐私与密钥风险 | [私密安全报告说明](../SECURITY.md) | 绝不公开泄漏细节或敏感数据 |
| 正式版本下载与更新日志 | [GitHub Releases](https://github.com/lichunboa/OrderCanvas/releases) | 发布版本和历史变更 |

**交流群入口**：2026-10-15 已完成 Bot 与用户交流群连接及成员入口实测。新用户先打开 [@OrderCanvasbot](https://t.me/OrderCanvasbot)，点击「进入交流群」获取当前可用的群邀请地址；不要公开私密运营群链接或过期邀请。MQL5 Market 购买与授权仍走 [平台商品页](https://www.mql5.com/en/market/product/201771)。

社区参与以帮助用户解决问题为主，不使用刷评、虚构收益和未声明身份的产品软广告；遵守各平台版规。

**公开 GitHub 不上传：**MT5 真实账户号码、订单号、交易记录、激活码、支付信息、密码、私钥、其他可识别客户的日志和截图。请用模拟数据并做脱敏。

开源贡献者也请阅读 [CONTRIBUTING.md](../CONTRIBUTING.md) 和 [社区准则](../CODE_OF_CONDUCT.md)。
