# OrderCanvas：哪些部分开源，哪些部分仍为商业软件？

[English](OPEN_SOURCE.md) · [开源工具](../OpenUtilities/) · [开源指标](../TVStudySuite/) · [商业许可证](../LICENSE)

OrderCanvas 采用 **开源基础模块 + 商业闭源交易面板** 的模式。**GitHub 仓库公开，不代表所有代码都采用开源许可证。**

| 组成部分 | 许可证 | 当前公开内容 |
|---|---|---|
| `TVStudySuite/` 价格行为指标工作台 | **MPL-2.0** | 已开放移植后的源代码和许可、原作者致谢；基于第三方开源 TradingView 指标 |
| `OpenUtilities/` 通用工具 | **MIT** | 已开放预算换算手数、K 线倒计时、有效期日历、垂直区域重叠判断、鼠标价格轴数学、滚轮缩放数学及对应测试 |
| `OrderCanvas.ex5` 商业面板、下单 UI、订单线、交易执行、授权校验 | **专有商业许可** | 仅发布编译成品，不开放这些模块的商业源代码 |
| 未另行授权的截图及文档 | 参见仓库根 [LICENSE](../LICENSE) | 可公开浏览，但不自动等于 MIT/MPL |

## 第三方来源

TVStudySuite 移植了三个第三方开源指标：Price Action All In One、Al Brooks Second Entry、Al Brooks - Bar Count。具体作者、原始链接及说明见 [TVStudySuite/NOTICE.md](../TVStudySuite/NOTICE.md)。**三个原始 Pine 脚本的精确源码许可证声明和版本尚待逐一核验**：目前确认的是原始页面公开源码，以及 TradingView 默认采用 MPL-2.0（原作者另选许可证的情况除外）。详情见 [逐模块第三方来源记录](../TVStudySuite/MQL5/Indicators/THIRD_PARTY.md)。原作者对自己的创作保留著作权；OrderCanvas 对合法独立创作与改编的部分拥有相应权利。我们不是 TradingView、MetaQuotes 或原作者的官方产品。

`OpenUtilities/` 则是从我们自己的 MQL5 项目中单独整理的、能脱离商业面板使用的小型基础函数；不包含商业交易执行和授权代码。第二批仅开放日历／能力位校验和区域重叠判断；与之相邻的挂单提交逻辑及专有面板布局算法仍不公开。第三批仅开放价格轴位移与滚轮缩放的独立数学运算；鼠标捕获、手势归属、释放防误点、订单线拖动状态机、渲染器仍然闭源。

## 商业使用与知识产权

- **MIT 模块可以免费商用**，遵守原版权声明与许可文本即可；无需购买 OrderCanvas。
- **MPL-2.0 指标可以合法使用、修改、再分发**，但涉及受 MPL 覆盖文件的源代码开放及声明义务必须继续遵守。
- 商业 OrderCanvas 的 EX5、交易面板以及激活码仍适用 [商业专有许可](../LICENSE)，购买产品不等于获得复制面板源码、转售或绕过授权的许可。
- 授权算法是否公开和签名私钥是否公开是两件事：**密钥、客户账号、订单数据库和授权签名秘密绝不公开**。

## 欢迎怎样的贡献？

欢迎为明确开放的目录提交独立测试、兼容性修复、文档和跨经纪商边界案例。请阅读 [贡献指南](../CONTRIBUTING.md)。GitHub 公共 Issue 不要包含真实交易账户、许可证密钥、密码或尚未披露的漏洞。

后续我们会按批次评估可独立开放的模块：首先核实代码来源、许可证、依赖和测试，再决定是否发布。**候选清单不构成已经开放或承诺开源的声明。**
